# Sidekick

Sidekick is a Wear OS remote companion for Codex. It keeps ongoing Codex work within reach when you are away from your computer.

Use it to start or continue tasks by voice, monitor progress from the app or Tile, respond to approvals, stop active work, and review concise task activity. The Codex app server remains the source of truth; the watch is a lightweight client connected over WebSocket.

## Build

```bash
./gradlew :wear:assembleDebug
```
